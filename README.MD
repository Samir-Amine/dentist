# 🦷 Cabinet Dentaire - Système de Prise de Rendez-vous

Formulaire en ligne pour la prise de rendez-vous automatisée avec confirmation WhatsApp.

## 📋 Fonctionnalités

- ✅ Formulaire HTML responsive en français
- ✅ Validation côté client (jours ouvrables, heures de travail, pause déjeuner)
- ✅ Intégration avec Make.com via Webhook
- ✅ Vérification automatique de disponibilité
- ✅ Confirmation par WhatsApp
- ✅ Enregistrement dans Google Sheets
- ✅ Synchronisation avec Google Calendar

## ⚙️ Configuration

### Horaires du Cabinet

- **Jours** : Lundi au Vendredi
- **Heures** : 09h00 - 18h00
- **Pause déjeuner** : 13h00 - 14h00 (fermé)
- **Durée rendez-vous** : 60 minutes
- **Créneaux disponibles** : 09h, 10h, 11h, 12h, 14h, 15h, 16h, 17h
